# 💡TheLightThingy

> *The ideal light controller for the ideal room*

![Poster1#](https://github.com/user-attachments/assets/96b906e6-7fff-4d11-bdaa-a18a7807428b)


## 🌟 Features
- It's a RGB led strip controller that allows me to control the colors mixture using three potentiometers!


## ℹ️ Overview

Hi, I'm Yassine Moustarziq and while I was sitting in my dorm. I realized that it's too boring, even after I added some posters, and my roommate agrees too! And after looking at other dorm rooms I realized what's missing, the component that makes almost every desktop pc cost 5x it's original price: RGB LED!!! 
So I made TheLightThingy to give some life to my room and so I can find an excuse to build something :)

## ⬇️ Components:

For the components needed you can find them in the component file, the prices are in rand but the final one is in dollars!
Note that right now only the South African list is out! The WorldWide list will be out a bit later! Thank you for waiting :)

## ⬇️ PCB:

This time, I wanted to challenge myself and built a PCB! You can find all the files needed in the PCB folder! Note that if you choose other components you might need to edit the PCB to make it fit!

## ⬇️ Code:

For this project to work, you need to use the Adafruit_NeoPixel library! You can check the .ino file in the Code folder and upload it using your Arduino IDE!

## ⬇️ 3D Model:
